# Mareas Watch Native V4 Oficial

Un único APK para Android móvil y Wear OS.

## Cambio principal
Las horas y alturas de pleamar/bajamar ya no se calculan con el modelo senoidal local. La app selecciona por GPS la estación más cercana de la API oficial de mareas del Instituto Hidrográfico de la Marina y consulta sus predicciones. La gráfica interpola suavemente entre esos extremos oficiales.

Para Valdelagrana, la estación próxima esperada es El Puerto de Santa María (IHM id 41), no Cádiz.

## Compilar
Sube el contenido interior del ZIP a un repositorio nuevo. Ejecuta Actions > Generar APK V4 Oficial. Descarga MareasWatchNativeV4Oficial-APK.
